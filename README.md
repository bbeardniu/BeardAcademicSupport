# Beard Academic Support

Static landing page for GitHub Pages.

## Publish

1. Create a new GitHub repository named `beard-academic-support`.
2. Upload `index.html` and `styles.css` to the repository root.
3. In the repository, open **Settings → Pages** and choose **Deploy from a branch**, then select `main` and `/ (root)`.
4. GitHub will publish the site at `https://<your-github-username>.github.io/beard-academic-support/`.

The request buttons already link to the Google Form and the assessment section links to GoalChecks.
